# archive/

Point-in-time snapshots and hand-off copies. Not part of the live project;
the working code, docs, and tests live at the repo root (`src/`, `docs/`,
`tests/`, ...). Nothing here is collected by `pytest`.

- `7.15.25/` — dated session snapshot (source + tests + report as of that day).
- `sharing/` — a curated read-only copy of the project basics, with plain
  notes added to the code so someone can understand it without reading the
  whole repo. See `sharing/README.md` for the intended reading order.
